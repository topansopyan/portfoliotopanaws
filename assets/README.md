# Assets

Static assets for the portfolio.

| File          | Purpose                                                        |
|---------------|----------------------------------------------------------------|
| `resume.html` | Printable resume page (print to PDF from the browser).         |

| `profil.png`  | Profile photo shown in the hero (clipped into a circle).       |

## Profile photo

The hero uses `profil.png`. To swap it, replace that file (keep the name) or
update the `<img src="assets/profil.png">` reference in `../index.html`. The
`.profile-card__photo` style already clips the image into a circle via
`object-fit: cover`.
