# Pages

This portfolio is a **single-page application** — one continuously scrolling
page (`../index.html`) with a sticky top navigation that jumps to each section.

## Sections (anchors)

| Anchor      | Section   | Content                                             |
|-------------|-----------|-----------------------------------------------------|
| `#hero`     | Beranda   | Fullscreen landing: badge, typewriter intro, CTAs   |
| `#about`    | Tentang   | Bio, highlights, animated statistic cards           |
| `#skills`   | Keahlian  | Tech-stack cards (data-driven)                      |
| `#projects` | Project   | Featured project cards (data-driven)                |
| `#contact`  | Kontak    | Email, phone, portfolio, location                   |

## Standalone page

- `../assets/resume.html` — a printable resume (open, then "Cetak / Simpan
  sebagai PDF"). Opened in a new tab from the Resume / Download Resume buttons.

Because the design is single-page, additional pages are intentionally not split
into separate HTML files. If the site grows, new standalone pages can be added
here and linked from the navbar.
